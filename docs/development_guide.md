## 2. 核心引擎详解

### 2.1 签名引擎 (SignatureEngine)

特征码查杀是最基础、最快速的检测方式。引擎维护一个包含数万条病毒签名的数据库，每条签名包含：

- MD5/SHA1/SHA256 哈希值
- 病毒名称和类型
- 威胁等级
- 病毒家族
- 大小范围

扫描时计算文件的哈希值，与数据库中的签名进行比对。匹配成功即判定为恶意。

### 2.2 启发式引擎 (HeuristicEngine)

启发式引擎不依赖病毒库，通过分析文件特征来检测未知威胁：

- **PE分析器**：解析PE文件头、节区表、导入表，检测加壳/混淆、异常入口点、可疑节区
- **脚本分析器**：分析PowerShell/JS/VBS/BAT脚本，检测混淆、编码、恶意API调用
- **文档分析器**：检测Office宏、PDF JavaScript、嵌入对象
- **通用分析器**：文件熵值、头尾不匹配、空字节比例

评分系统对各个维度的检测结果进行加权计算，给出最终的风险评分。

### 2.3 行为引擎 (BehaviorEngine)

行为引擎通过实时监控系统活动来检测恶意行为：

- **进程监控**：检测进程创建、注入、提权
- **文件监控**：监控文件创建、修改、删除，检测勒索软件批量加密行为
- **注册表监控**：监控启动项、浏览器劫持、文件关联修改
- **网络监控**：监控异常外连、C2通信、端口扫描

行为规则引擎对捕获的事件进行关联分析，匹配预定义的恶意行为模式。

### 2.4 云查杀引擎 (CloudEngine)

云查杀引擎将文件哈希发送到云端服务器查询：

- 支持隐私模式（仅发送哈希）
- 本地LRU缓存减少重复查询
- 离线模式自动降级
- 缓存持久化到磁盘

## 3. 自我保护机制

### 3.1 进程保护
- 提升进程优先级为HIGH
- 双进程看门狗互相监控
- 阻止任务管理器结束进程

### 3.2 文件保护
- 保护安装目录和配置文件
- 监控文件完整性
- 自动恢复被篡改的关键文件

### 3.3 注册表保护
- 保护自启动注册表项
- 监控安全策略变更
- 自动修复被篡改的注册表

## 4. 清理修复流程

### 4.1 恶意软件清除流程
1. 终止恶意进程
2. 将文件移动到隔离区
3. 清理注册表启动项
4. 清理恶意服务
5. 清理计划任务
6. 清理浏览器扩展

### 4.2 系统修复流程
1. 备份当前状态
2. 修复Hosts文件
3. 修复文件关联
4. 修复浏览器设置
5. 修复网络设置
6. 运行SFC检查

## 5. 防火墙规则

### 5.1 默认规则
- 允许本地回环流量
- 阻止高危端口入站（135, 139, 445, 3389）
- 阻止未知程序外连

### 5.2 入侵检测
- 端口扫描检测（60秒内超过20个连接）
- 暴力破解检测
- DDoS攻击检测

## 6. 性能优化

### 6.1 CPU优化
- 扫描线程数可配置（默认4）
- 低优先级扫描（不抢占用户操作）
- 闲时深度扫描

### 6.2 内存优化
- 分块读取大文件（64KB块）
- 缓存LRU淘汰策略
- 延迟加载非关键模块

### 6.3 I/O优化
- 使用mmap高效读取文件
- 批量提交扫描结果
- 异步日志写入

## 7. 扩展开发

### 7.1 添加新的扫描引擎
```python
from engine import ScanEngine, ThreatInfo, ScanResult

class MyEngine(ScanEngine):
    def __init__(self):
        super().__init__('MyEngine', enabled=True)
    
    def scan(self, filepath):
        # 实现扫描逻辑
        if self._is_malicious(filepath):
            return ThreatInfo(
                file_path=filepath,
                threat_name='MyEngine.Detection',
                scan_engine=self.name,
                threat_level=4,
                result=ScanResult.MALICIOUS
            )
        return None
```

### 7.2 添加新的HIPS规则
```python
from engine.behavior.behavior_engine import BehaviorRule

new_rule = BehaviorRule(
    rule_id='C001',
    name='自定义规则',
    description='检测特定行为',
    event_type='process',
    actions=['CreateProcess'],
    target_patterns=['suspicious.exe'],
    score=20,
    level=4,
    min_count=1,
    time_window=60
)
```

## 8. 部署配置

### 8.1 环境要求
- Windows 10/11 x64
- Python 3.8+
- 4GB RAM
- 500MB 磁盘空间
- 管理员权限（实时防护）

### 8.2 安装步骤
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行
python main.py

# 3. 安装为服务（管理员）
python main.py --service install
python main.py --service start
```

### 8.3 配置文件
配置文件 config.json 位于安装目录，支持运行时修改：
- general: 通用设置
- realtime: 实时防护
- scan: 扫描设置
- cloud: 云查杀
- hips: 主动防御
- self_protection: 自我保护
- cleanup: 清理修复
- firewall: 防火墙
- logging: 日志

## 9. 故障排除

### 9.1 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 无法启动GUI | 缺少PyQt5 | pip install PyQt5 |
| 扫描速度慢 | 线程数太低 | 调整scan.thread_count |
| 实时防护不工作 | 权限不足 | 以管理员身份运行 |
| 更新失败 | 网络问题 | 检查网络连接 |

### 9.2 日志查看
日志文件位于 `D:/Antivirus/logs/`：
- tiandun.log - 主日志
- tiandun.error.log - 错误日志
- scan_results.log - 扫描结果
- threats.log - 威胁记录
- performance.log - 性能日志
