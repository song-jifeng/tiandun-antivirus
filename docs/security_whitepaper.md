# 天盾 Antivirus 安全架构白皮书

## 1. 安全设计原则

### 1.1 纵深防御 (Defense in Depth)

天盾 Antivirus 采用多层防御策略，确保单层失效时仍有其他层提供保护：

```
Layer 1: 签名检测 → 已知威胁快速识别
Layer 2: 启发式分析 → 未知威胁行为预判
Layer 3: 行为监控 → 实时拦截恶意行为
Layer 4: 云查杀 → 云端情报协同防御
Layer 5: HIPS → 主动防御系统
Layer 6: 防火墙 → 网络层过滤
Layer 7: 蜜罐 → 勒索软件诱捕
```

### 1.2 最小权限原则

- 扫描引擎仅获取必要的文件读取权限
- 实时防护模块使用Windows API的最低权限子集
- 网络监控仅监听不拦截（除非用户配置）
- 所有模块运行在用户态，不加载内核驱动

### 1.3 隐私保护

- 云查杀仅发送文件哈希，不发送文件内容
- 扫描结果仅存储在本地
- 不收集用户个人信息
- 不上传文件样本
- 网络连接可完全禁用

## 2. 威胁检测模型

### 2.1 特征匹配模型

```
输入: 文件路径
  ↓
计算文件哈希 (MD5 + SHA1 + SHA256)
  ↓
查询签名数据库
  ↓
命中? → 是 → 返回威胁信息
  ↓
  否
  ↓
YARA规则匹配
  ↓
命中? → 是 → 返回威胁信息
  ↓
  否
  ↓
返回安全
```

### 2.2 启发式评分模型

```
输入: 文件路径
  ↓
PE分析 → 分数: 0-100
脚本分析 → 分数: 0-100
文档分析 → 分数: 0-100
通用分析 → 分数: 0-100
  ↓
加权计算总分
  ↓
总分 > 阈值? → 是 → 返回可疑/恶意
  ↓
  否
  ↓
返回安全
```

### 2.3 行为关联模型

```
输入: 系统事件流
  ↓
事件分类: 进程/文件/注册表/网络
  ↓
时间窗口聚合 (60秒)
  ↓
规则匹配
  ↓
规则命中? → 是 → 行为关联分析
  ↓                    ↓
  否              威胁评分
  ↓                    ↓
继续监控         达到阈值?
                     ↓
                是 → 告警/拦截
```

## 3. 性能模型

### 3.1 扫描性能模型

```
单文件扫描时间 = 文件读取时间 + 哈希计算时间 + 签名查询时间 + 启发式分析时间

文件读取时间 = 文件大小 / 读取速度 (通常 500MB/s+)
哈希计算时间 = 文件大小 * 哈希速度 (MD5: ~500MB/s)
签名查询时间 = O(1) 哈希表查找
启发式分析时间 = 文件大小 * 分析因子 (通常 < 10ms)
```

### 3.2 内存模型

```
核心进程内存 = 引擎代码 + 签名数据 + 缓存 + 运行时数据

引擎代码: ~5MB (Python + 依赖库)
签名数据: ~3MB (10000条签名)
缓存: ~1MB (LRU缓存)
运行时数据: ~1MB (事件队列、统计信息)
总计: ~10MB (空闲状态)
```

### 3.3 并发模型

```
扫描线程数 = min(CPU核心数, 配置最大线程数, 16)

全盘扫描吞吐量 = 扫描线程数 * 单线程吞吐量
单线程吞吐量 = 1 / 平均单文件扫描时间
平均单文件扫描时间 = 2ms (SSD) / 10ms (HDD)
```

## 5. 数据存储安全

### 5.1 配置文件安全

- 配置文件存储在安装目录
- 敏感信息使用环境变量
- 配置文件权限设置为仅管理员可写

### 5.2 隔离区安全

- 隔离文件存储在专用隔离目录
- 文件名使用哈希重命名
- 隔离索引使用JSON格式持久化
- 隔离区权限设置为仅系统账户可访问

### 5.3 日志安全

- 日志文件存储在专用日志目录
- 自动轮转和压缩
- 不记录敏感信息
- 日志清理策略

## 6. 风险评估模型

### 6.1 威胁评分

```
威胁评分 = 特征码评分 + 启发式评分 + 行为评分 + 云查杀评分

特征码评分: 匹配签名则100分，否则0分
启发式评分: 0-100分 (基于多维度分析)
行为评分: 0-100分 (基于行为规则匹配)
云查杀评分: 0-100分 (基于云端置信度)
```

### 6.2 风险等级

```
严重 (5): 评分 >= 85
高危 (4): 评分 >= 65
中等 (3): 评分 >= 45
低危 (2): 评分 >= 25
信息 (1): 评分 >= 10
无害 (0): 评分 < 10
```

## 7. 应急响应流程

### 7.1 威胁发现响应

```
1. 检测到威胁
2. 立即隔离文件
3. 终止关联进程
4. 清理注册表和启动项
5. 记录威胁日志
6. 通知用户
7. 提供修复建议
```

### 7.2 系统崩溃恢复

```
1. 检测进程异常退出
2. 看门狗自动重启
3. 检查完整性
4. 恢复配置
5. 继续监控
```

### 7.3 勒索软件应急响应

```
1. 蜜罐告警触发
2. 立即阻止文件修改
3. 终止可疑进程
4. 通知用户
5. 提供文件恢复建议
```

## 11. 安全建议

### 11.1 系统配置

1. 保持操作系统更新
2. 使用标准用户账户
3. 启用UAC
4. 关闭不必要的服务
5. 使用BitLocker加密

### 11.2 网络安全

1. 启用Windows防火墙
2. 使用安全的DNS
3. 禁用不必要的端口
4. 使用VPN保护隐私
5. 定期检查网络连接

### 11.3 行为安全

1. 不点击可疑链接
2. 不下载未知附件
3. 使用强密码
4. 启用双因素认证
5. 定期备份重要数据
