# 天盾 Antivirus 用户手册

## 第一章：快速入门

### 1.1 安装

天盾 Antivirus 是一款纯Python开发的杀毒软件，无需复杂的安装过程。

**系统要求：**
- 操作系统：Windows 10/11 (64位)
- Python版本：3.8或更高
- 内存：4GB及以上
- 磁盘空间：500MB可用空间
- 权限：管理员权限（用于实时防护和系统修复）

**安装步骤：**

第一步：安装Python依赖
```bash
pip install -r requirements.txt
```

第二步：运行杀毒软件
```bash
python main.py
```

第三步：（可选）安装为系统服务
```bash
python main.py --service install
python main.py --service start
```

### 1.2 启动界面

启动后，您将看到天盾 Antivirus 的主界面，包含以下部分：

- **左侧导航栏**：包含首页、病毒扫描、实时防护、防火墙、隔离区、日志、设置
- **右侧内容区**：显示当前选中的功能页面
- **顶部状态栏**：显示防护状态和版本信息

### 1.3 首次使用建议

1. 首先执行一次"快速扫描"，检查系统关键路径
2. 确认实时防护已开启（默认开启）
3. 检查病毒库版本是否为最新
4. 根据需要调整扫描设置

## 第二章：病毒扫描

### 2.1 扫描模式

天盾 Antivirus 提供三种扫描模式：

**快速扫描**
- 扫描范围：系统关键路径
- 包括：系统目录、启动项、临时文件夹、注册表
- 耗时：1-3分钟
- 适用场景：日常快速检查

**全盘扫描**
- 扫描范围：所有驱动器
- 包括：所有文件、压缩包、内存
- 耗时：30分钟-2小时
- 适用场景：全面安全检查

**自定义扫描**
- 扫描范围：用户指定的文件或文件夹
- 适用场景：针对特定位置进行扫描

### 2.2 扫描设置

在设置页面可以调整：

- **扫描线程数**：默认为4，可根据CPU核心数调整
- **最大文件大小**：超过此大小的文件将被跳过，默认200MB
- **启发式分析级别**：低/中/高，级别越高检测率越高，但误报也越多
- **压缩包扫描**：是否扫描压缩包内的文件

### 2.3 扫描结果

扫描完成后，结果会显示在扫描页面：

- **绿色**：安全文件
- **黄色**：可疑文件（需要进一步分析）
- **红色**：恶意文件（需要立即处理）

对检测到的威胁，您可以：
- **隔离**：将文件移动到隔离区，安全保存
- **删除**：直接删除文件（不可恢复）
- **信任**：将文件加入白名单，不再扫描

## 第三章：实时防护

### 3.1 防护模块

实时防护包含以下模块：

**文件监控**
- 监控文件的创建、修改、删除操作
- 检测勒索软件批量加密行为
- 监控自启动目录的变更

**进程监控**
- 监控新进程的创建
- 检测进程注入行为
- 检测可疑的父子进程关系

**注册表监控**
- 监控启动项的修改
- 检测浏览器劫持
- 监控文件关联变更

**网络监控**
- 监控网络连接建立
- 检测异常外连行为
- 识别C2通信

### 3.2 防护级别

- **低**：仅监控最关键的事件
- **正常**：监控所有重要事件（推荐）
- **高**：监控所有事件，可能会产生较多告警

### 3.3 排除列表

您可以将信任的文件或路径添加到排除列表：
- 被排除的文件将不会被扫描
- 被排除的路径下的所有文件都将被忽略
- 支持通配符模式

## 第四章：防火墙

### 4.1 防火墙规则

防火墙内置了以下默认规则：
- 允许本地回环流量
- 阻止高危端口入站（135、139、445、3389）
- 阻止未知程序的出站连接

### 4.2 入侵检测

入侵检测系统（IDS）可以检测：
- 端口扫描：60秒内超过20个外部连接尝试
- 暴力破解：短时间内多次登录失败
- 异常流量：突然增加的网络流量

### 4.3 勒索软件诱捕

勒索软件诱捕系统会在以下位置放置蜜罐文件：
- 桌面
- 文档文件夹
- 图片文件夹
- 下载文件夹

当蜜罐文件被修改或删除时，系统会立即告警，并尝试拦截。

## 第五章：隔离区

### 5.1 隔离机制

当检测到威胁时，文件会被移动到隔离区：
- 文件被安全加密存储
- 原始文件被删除
- 隔离记录包含原始路径、检测时间、威胁类型等信息

### 5.2 隔离操作

- **查看**：查看隔离区文件列表
- **还原**：将文件恢复到原始位置
- **删除**：永久删除隔离文件
- **清空**：删除所有隔离文件

### 5.3 自动清理

隔离区文件默认保留30天，过期后自动清理。您可以在设置中调整保留天数。

## 第六章：自我保护

### 6.1 进程保护

天盾 Antivirus 的核心进程受到保护：
- 任务管理器无法直接结束进程
- 双进程看门狗互相监控
- 进程异常退出时自动恢复

### 6.2 文件保护

安装目录和关键配置文件受到保护：
- 防止病毒修改杀毒软件文件
- 文件完整性监控
- 自动恢复被篡改的文件

### 6.3 注册表保护

杀毒软件的注册表项受到保护：
- 防止病毒禁用杀毒软件
- 监控启动项变更
- 自动修复被篡改的注册表

## 第七章：清理修复

### 7.1 恶意软件清除

清除恶意软件时，系统会执行以下操作：
1. 终止恶意进程
2. 隔离或删除恶意文件
3. 清理注册表启动项
4. 删除恶意服务
5. 删除计划任务
6. 清理浏览器扩展

### 7.2 系统修复

系统修复功能可以修复：
- Hosts文件被篡改
- 文件关联被修改
- 浏览器主页被劫持
- 网络设置被修改
- 系统文件被替换

### 7.3 文件恢复

文件恢复功能可以：
- 恢复被隐藏的文件
- 恢复被修改的文件关联
- 恢复桌面图标
- 系统文件检查

## 第八章：云查杀

### 8.1 工作原理

云查杀引擎将文件哈希发送到云端服务器：
- 仅发送文件哈希，不发送文件内容（隐私保护模式）
- 云端返回匹配结果
- 本地缓存查询结果，避免重复查询

### 8.2 离线模式

当无法连接到云端服务器时：
- 自动切换为离线模式
- 仅使用本地病毒库进行检测
- 恢复连接后自动切换回在线模式

## 第九章：性能优化

### 9.1 CPU优化

- 扫描线程数可配置（默认4）
- 低优先级扫描，不抢占用户操作
- 闲时深度扫描

### 9.2 内存优化

- 分块读取大文件（64KB块）
- 使用LRU缓存淘汰策略
- 延迟加载非关键模块

### 9.3 I/O优化

- 使用mmap高效读取文件
- 批量提交扫描结果
- 异步日志写入，不阻塞主流程

## 第十一章：常见问题

### 11.1 安装问题

**Q: 安装依赖时出错？**
A: 确保使用最新版本的pip：`pip install --upgrade pip`

**Q: 提示缺少DLL？**
A: 安装Visual C++ Redistributable for Visual Studio 2015-2022

### 11.2 使用问题

**Q: 扫描速度很慢？**
A: 在设置中增加扫描线程数，或减少最大文件大小

**Q: 实时防护未生效？**
A: 确保以管理员身份运行程序

**Q: 误报正常文件？**
A: 将文件加入排除列表，或降低启发式分析级别

**Q: 无法更新病毒库？**
A: 检查网络连接，或手动下载病毒库更新包

### 11.3 性能问题

**Q: 杀毒软件占用内存过高？**
A: 减少缓存大小，或降低监控级别

**Q: 游戏时卡顿？**
A: 开启游戏模式，在设置中降低扫描优先级

## 第十二章：安全建议

### 12.1 日常使用

1. 保持实时防护始终开启
2. 每周执行一次快速扫描
3. 每月执行一次全盘扫描
4. 及时更新病毒库
5. 定期检查隔离区

### 12.2 网络安全

1. 不要点击来历不明的链接
2. 不要下载不明来源的文件
3. 使用强密码
4. 开启防火墙
5. 定期检查网络连接

### 12.3 系统安全

1. 保持Windows更新
2. 使用标准账户而非管理员账户
3. 关闭不必要的服务和端口
4. 定期备份重要数据
5. 使用加密存储敏感信息
